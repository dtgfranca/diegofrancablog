I'm Diego França, a Software Architect and writer behind the blog diegofranca.dev.

My focus is writing about PHP, different kinds of testing, building pipelines, and occasionally sharing summaries of tech books.

This blog started in 2019, when I was going through a rough patch — I couldn't seem to finish any project I started. Then I thought about starting this blog, and to get a kick start I bought a domain with my name and a ready-made layout for the blog (I knew that if I tried to build it from scratch, I wouldn't finish it).

Putting the blog live gave me a new focus and the opportunity to write about many different topics. Today I treat this blog as a place where I can write down everything I learn and don't want to forget — something I can consult whenever I have a doubt about a subject.
