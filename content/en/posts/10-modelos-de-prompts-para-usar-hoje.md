### What is a prompt?

A prompt is a phrase or a text that the AI agent will use to respond. AI models are great at following instructions, but a poorly constructed prompt can also generate bad answers. The most important thing to get the most out of it is to know how to write a good prompt. I see many people writing bad prompts and even giving up on using the AI model. To make sure that doesn't happen to you, I'll show how we can use prompts correctly.

### Zero-shot

Zero-shot is a technique where the language model is given only the task to be done, with no example of how the task should be performed.

- When to use
  - The task is simple and well-known to the model.
  - There's no time or space to add examples.
  - You want the ability to learn without an example of how the task should be done.
  - You need to process a large number of tasks and save tokens.
  - You don't know what should be done.
- Advantages
  - Simple to use.
  - Can be used for simple tasks.
- Disadvantages
  - Can generate incomplete answers.
  - Can generate hallucinations.

- Examples:
  Prompt: I want to make a pizza with cheese and ham. Can you help me?

### One-shot / Few-shot

- When to use
  - When you have one or more similar tasks.
  - When you can provide one or a few examples of how the task should be done.
- Advantages
  - The model "learns" from the examples.
  - Useful for more complex tasks or tasks that require consistency.

- Disadvantages
  - Consumes more tokens.
  - The prompt can become more complex.

  - Examples

    One-shot example

    Prompt:

    ```
    Following this pattern: I like to play soccer → I love to play soccer.
    Translate to English: It's going to rain today.
    ```

    Few-shot example

    ```
    Translate to English following this format:

    Example 1:
    Portuguese: I like to program in PHP.
    English: I like to program in PHP.

    Example 2:
    Portuguese: It's raining a lot today.
    English: It is raining a lot today.

    Now translate:
    Portuguese: Tomorrow I'm going to the market.
    English:
    ```
